# Security policy

Congelator is in development. There are currently no supported releases.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/kgrab75/congelator/security/advisories/new) to contact the maintainer. Keep vulnerability details out of public issues and pull requests.

Include the affected version or commit, the affected component, the expected impact, and enough detail to review the report safely. Use synthetic data and remove credentials, personal information, and private infrastructure details. Keep disclosure coordinated with the maintainer through the private report.

See the [technical security and observability documentation](docs/SECURITY.md) for Congelator's security design.
